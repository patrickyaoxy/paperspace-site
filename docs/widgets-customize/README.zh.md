# 小组件与图标自定义演示

从首页「小组件与图标自定义」或主导航进入五套完整首页搭配，以及小组件和11×11两态点阵图标的设备操作回放。网页播放的是已录制操作，不能将网页中的修改同步到设备。

全部33张画面由 v2.1.1 stable 同源码模拟器渲染，非实机照片；684×1216原帧通过现有PLFB解码器直接转换为无损PNG，未重画设备界面。精确来源提交为 `3abe593b3ad208229aaf734b879af2f5081c6cec`。逐帧来源、配置和SHA-256见[来源清单](../../assets/customize-stable/provenance.json)。模拟器回放节奏不代表墨水屏刷新时间、残影或功耗。

五套搭配为官网示例，并非设备内置主题。设备中先调整草稿、预览，再应用；应用后仍停留编辑页，需要自行返回首页。图标常态与激活态分别编辑，应用保存整套图标。

模块、样式及图片在区域接近视口后载入。图片加载失败时保留上一张完整画面，并可重试；减少动态效果设置保留手动操作。原网站其他画面与浏览器实时程序保留各自2.0.8身份。

画面使用官网既有公开演示短书、原创书封与字体。字体为 LXGW WenKai Mono GB Regular 1.530，遵循[现有SIL OFL 1.1许可](../../assets/fonts/OFL.txt)；其他来源与许可见[许可与鸣谢](../../legal.html)。
