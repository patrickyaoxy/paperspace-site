01 / 日常使用

先熟悉这几件事。

如何安排主页？

进入 设置 → 外观 → 主页小组件，在布局、内容与外观中调整。先预览，再应用。未保存的草稿与正式主页应分开判断。

怎样换成竖排阅读？

在阅读视图相关设置中选择横排或左右双向竖排，并按喜好调整方向、字号与注释。官网原帧导览回放实际截图；实时区直接运行同源 WASM，可操作隔离演示卡，不修改设备设置。

怎样编辑点阵图标？

设置 → 外观 → 图标编辑。常态与激活态可编辑，支持整套应用与预设。轻体验展示实际编辑页，不上传修改。

怎样使用轻应用？

从正式渠道取得匹配版本的 .elapp 包，在设备按说明检查权限并安装。应用中心管理已安装的自有应用。此网站没有安装服务。

02 / 用 AI 做一个小应用

从真实接口开始。

先读 AI quickstart、包格式与实际实现，再参考 Lua 示例和 manifest。API 有版本、权限与资源预算，按设备实际支持的版本开发。

  1. 明确一屏用途、交互区域与持久化含义。
  2. 选择 API 版本并声明必要 / 可选权限。
  3. 编写 manifest.json、main.lua 与可选图标。
  4. 打包、检查并测试失败和恢复路径。

依据 docs/lightapp-ai-quickstart.md
示例：gomoku / zen_clock / web_reader

接口能力与边界

知道能做什么，也知道做到哪里。

版本 / 能力仓库合同边界
API 2 / 绘图与交互host.width / height、绘图、触摸回调、自身 int32 存档按实际旋转画布布局；保存成功后再显示成功
API 3 / 日期与阅读查询reading.read 安装权限只读已提交统计、最近书目与保存进度
API 4 / 资料与专注notes.write / tasks.write / focus.control有界创建与显式控制；没有任意文件与正文修改
API 5 / HTML 排版host.html_open / host.browser_open；html.render 权限browser_open 还需 network 且仅限 on_open；HTML ≤ 16 KiB，不执行脚本、CSS、登录或表单

外部能力在 manifest.permissions.required / optional 中分别声明：必要权限不接受则不安装，可选权限默认关闭、可在管理页调整；运行时不弹授权窗。network 仅提供有界异步 GET。普通绘图文本每条至多 95 UTF-8 字节，每快照至多 32 条命令；HTML 正文另有预算。不提供后台任务、POST / 自定义请求头、任意文件或通用系统控件。完整合同以 v2.0.8 文档与实现为准。
